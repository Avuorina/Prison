# Prison

刑務所RPシステム

## 動作環境
- Minecraft Java Edition 26.3
- Fabric Loader 0.19.5
- リソースパック：[PrisonAsset](https://github.com/Avuorina/PrisonAsset)(非公開)

## 必要なMod
Fabric 版。バージョンは 2026-10-17 時点で 26.3 向けの最新。プレイヤー全員がクライアントに入れる。

| Mod | バージョン | 役割 |
| --- | --- | --- |
| [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights) | 4.13.0+26.3 | 手に持ったランタンで周りを照らす |
| [Fabric API](https://modrinth.com/mod/fabric-api) | 0.163.0+26.3 | LambDynamicLights に必要 |

LambDynamicLights は全員そろえないと見え方に差が出るので、必ず入れる。
