# 通しテスト チェックリスト

ゲーム開始から脱獄成功まで、ひと通り動くかを確かめる。
時間の欄には、その手順にかかった実時間を書く(目標は全体で約13時間・30日以内)。

## 0. 準備
- [ ] リソースパック(PrisonAsset)と LambDynamicLights を全員が入れている
- [ ] GMブックを受け取る(`/function main:book/gm`)
- [ ] [監視カメラを置き直す] [処刑日数の表示を置き直す] を押す
- [ ] [看守を登録] で看守を決める
- [ ] [囚人をランダム配置] で、囚人が4〜7番の房に送られる
- [ ] 房の扉の上に、囚人の名前と「30日」が出る
- [ ] [看守にゲーム開始を渡す] → 看守が右クリックで開始できる

## 1. 開始直後
- [ ] 囚人：囚人服(脱げない)とランタンだけを持っている
- [ ] 看守：警棒・手錠・マスターキー・日課の速さを持っている
- [ ] 「1日目」のタイトルが出て、起床・点呼から日課が始まる
- [ ] ボスバーに時刻とフェーズ、残り時間が出る
- [ ] リセットで本・チェスト・壊したブロック・レシピが元に戻っている

## 2. 日課
- [ ] 1日がちょうど実時間30分で回る
- [ ] 奇数日が作業日、偶数日が免業日になる
- [ ] 消灯の間だけ電球が消える
- [ ] 起床のとき、畑のチェストが補充される
- [ ] 日課の速さ(等速→1/2→1/10→停止)が切り替わる
- [ ] 夜の空・時刻がフェーズに合っている

## 3. 脱獄ルート(囚人) 時間：____
- [ ] 房のトイレの下の泥を掘れる(4つの房すべて)
- [ ] ボロボロの手帳を読むと、木のシャベルのレシピが解放される
- [ ] 厨房の作業台で木のシャベルが作れる
- [ ] 畑の掘れる土から、前任者の隠れ家に入れる
- [ ] 隠れ家の手帳②で木の斧のレシピが解放される
- [ ] 欠けた石のツルハシで、房の下の滑らかな玄武岩が1回だけ壊せる
- [ ] 隠れ家のレバーで、下水道への鉄のトラップドアが開く
- [ ] 看守用倉庫で、破れた園芸メモ・丸石・苗木が手に入る
- [ ] 苗木を地下で育てられる(松明が要る)
- [ ] 原木を拾うと木のツルハシ、丸石を拾うと石のツルハシのレシピが解放される
- [ ] 薪を置いて斧で殴ると、皮をはいだ原木になる(斧の耐久が1減る)
- [ ] 竈で薪を焼いて木炭 → 木炭＋棒で松明が作れる
- [ ] 板材を置いて斧で殴ると棒が2本
- [ ] 鉄の鎖をつるはしでばらすと鉄塊3つ → 鉄塊9個で鉄インゴット
- [ ] 鉄のツルハシで錆止めされた銅格子が壊せる
- [ ] 紫の鍵で武器庫の扉が開き、火薬とレッドストーンが手に入る
- [ ] ボイラー室で発破の記録・レッドストーン・火打石が手に入る
- [ ] 火薬5＋レッドストーン4でファイヤーチャージ → 砂で囲んでTNT
- [ ] 火打石と打ち金が作れる
- [ ] ダイヤのツルハシで、酸化した銅のドアが壊せる(ダイヤはマップに2つ＋GMが1つ)
- [ ] 水門を閉めて、TNTを cinnabar に置いて爆破できる
- [ ] 水門が開いた瞬間に看守へ通知が来る
- [ ] 塀の外に出ると看守に通知が来て、10秒耐えると脱獄成功
- [ ] 脱獄した囚人がスペクテイターになり、扉の上が「脱獄」になる

## 4. 看守の道具
- [ ] 警棒2発で囚人を倒せる
- [ ] 手錠で殴ると、2つの懲罰房のどちらかに送られ、場所がチャットに出る
- [ ] マスターキーで、すべての鍵穴(オレンジ・深層岩タイルも)が開く
- [ ] 色の鍵は、同じ色のコンクリートの鍵穴だけ開く
- [ ] 房の扉の上の表示をクリック → [懲罰 −1日] [恩赦 +1日] で日数が変わる
- [ ] 0日の翌朝に処刑され、スペクテイターになる

## 5. 監視カメラ
- [ ] モニターをクリックでカメラの視点になる
- [ ] 右クリックで次のカメラ、スニークで戻る
- [ ] 見ている間、看守は透明で、その場にダミーが残る
- [ ] 看守の画面にカメラの模型が映り込まない
- [ ] 見回すと、模型もその場で首を振る
- [ ] 持ち物が全部預けられ、戻ると同じスロットに返る

## 6. 所持品検査ゲート
- [ ] レッドストーンブロックの床：金属で鳴る
- [ ] コマンドブロックの床：何か持っていたら鳴る(ランタンだけなら鳴らない)
- [ ] アメジストブロックの床：禁制品で鳴る
- [ ] 鳴ると3秒光る・ランプが点く・ブザーが鳴る
- [ ] 看守は鳴らない
- [ ] ゲートの上でジャンプしても鳴り直さない

## 7. 見た目(リソースパック)
- [ ] 鍵6種・警棒・手錠・監視カメラのモデルが表示される
- [ ] カメラのリモコンと日課の速さが見えない
- [ ] ランタンを持つと周りが明るくなる(LambDynamicLights)

## 8. 終わり方
- [ ] 全員が脱獄か処刑になると、ゲームが終わる
- [ ] ゲームの途中で抜けた囚人が戻ってきても、続きから遊べる
